***** HOW TO INSTALL *****

Developer: Deepanshu Arora
Extension: Shipping Optimizer v1.8.2

DESKTOP (Chrome / Edge / Brave)
--------------------------------
1. Open chrome://extensions
2. Enable Developer mode
3. Click Load unpacked
4. Select this folder (must contain manifest.json)
5. Open supplier.meesho.com → catalog page → Shipping Optimizer

MOBILE (Kiwi Browser — Android)
--------------------------------
1. Zip this folder (manifest.json at the root of the zip)
2. Copy to phone → unzip
3. Kiwi → Extensions → Developer mode → Load unpacked
4. Pick the unzipped folder
5. Open supplier.meesho.com → Shipping Optimizer

No license key required.
See START_HERE_KIWI.txt for Kiwi details.
