# Meesho Shipping Cost Optimizer

Browser extension for Meesho sellers by **Deepanshu Arora**.

Generate image variants, check live shipping on Meesho, preview results, and apply the best image to your catalog in one click.

## Install (Chrome / Edge / Brave)

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder (must contain `manifest.json`)
5. Open `supplier.meesho.com` → catalog page → **Shipping Optimizer**

## Install (Kiwi Browser — Android)

See `START_HERE_KIWI.txt`.

## Features

- Live Meesho shipping checks
- Image preview and variant editor
- One-click apply to catalog front image
